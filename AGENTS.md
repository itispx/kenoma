# Agent Operating Rules

- Reading: allowed to read anything in the project, without restriction.
- Writing: allowed to write/edit files freely.
- Commands: do not run commands beyond reading the project and writing files, except lint.
- Read-only log inspection commands are allowed without asking first.
- Anything else — build, test, run, install, migrate, etc. — requires explicit permission from the user before running.
- Exception: the `impeccable` skill may run whatever commands it needs, without asking first.
